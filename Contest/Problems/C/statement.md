# Palindrome Check

Given a string **S**, determine if it is a palindrome (reads the same forwards and backwards). Ignore case.

## Input Format
A single line containing the string **S** (1 ≤ |S| ≤ 1000).

## Output Format
Print `YES` if the string is a palindrome, otherwise print `NO`.

## Sample Input
```
racecar
```

## Sample Output
```
YES
```
