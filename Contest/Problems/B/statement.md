# Maximum Element

Given an array of **N** integers, find the maximum element in the array.

## Input Format
First line: an integer **N** (1 ≤ N ≤ 10^5)
Second line: **N** space-separated integers

## Output Format
A single integer — the maximum element.

## Sample Input
```
5
3 7 2 9 1
```

## Sample Output
```
9
```
