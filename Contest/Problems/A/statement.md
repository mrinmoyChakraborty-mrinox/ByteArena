# Hello BYTEARENA

Write a program that reads two integers **a** and **b** and prints their sum.

## Input Format
Two integers separated by a space.

## Output Format
A single integer — the sum of **a** and **b**.

## Constraints
- -10^9 ≤ a, b ≤ 10^9

## Sample Input
```
3 5
```

## Sample Output
```
8
```
